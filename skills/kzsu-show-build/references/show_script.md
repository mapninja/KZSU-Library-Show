Rules:
- Number tracks 1 to N in Air Order sequence.
- Break slots follow a fixed pattern:
  - Hour 1: PSA after Set 1, PROMO after Set 2, PSA after Set 3.
  - Hour 2: PSA after Set 4, PROMO after Set 5.
  - Legal IDs at 18:00 and 19:00.
- Every talk-break fact has to hold up for a track that is still in the set, or stand on its own as a date fact. Before you finish, check each break against the set list above it.
- Use AP style: Oct. 1, 6-8 p.m., No. 1. Don't use em dashes, and don't write hype copy.
